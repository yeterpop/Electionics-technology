#### Questions for Amplifiers


**What is an Amplifier:**

- An amplifier is a device most commonly composed of a transistor that takes input signal and increases its output. The AC component is the input and the DC [[Bias]] is what actually amplifies the AC wave. 


**Types of Amps:**

- Common Emitter (Phase shift of 180)

- Common Collector (Low output impedance)

- Common Base 


**Differentiating between amps:**

- You can tell what amp configuration is used by where the AC current is following across the transistor. Common Base configurations looking radically different from common Emitter and collector.


**Impedance matching:**

-  The output and input of an amp must match in impedance so there is minimal loss of signal. 

**De coupling capacitor**

Prevents AC from going into the collector on a Common collector amp.
